# 20: Actions on notifications

**What to build:** For a menu-bar app, notifications are often the main way people interact. Add action buttons so the next step can be taken straight from the notification: Start Break on "Pomodoro Completed", and Start next Pomodoro on "Break Over" (on the Task of the last Pomodoro, if it isn't Done).

**Blocked by:** None (can start immediately)

**Status:** todo

- [ ] "Pomodoro Completed" offers a Start Break button that starts the due Short or Long Break.
- [ ] "Break Over" offers a button that starts a Pomodoro on the last Task, only when that Task isn't Done.
- [ ] If the action is no longer possible when pressed (e.g. the Day has ended), nothing breaks and the app shows why.
- [ ] Notifications name the Task the Pomodoro was on.
