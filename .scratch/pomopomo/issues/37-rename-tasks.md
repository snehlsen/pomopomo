# 37: Rename Tasks

**What to build:** A typo in a Task's name can only be fixed by deleting and re-adding the Task. Allow renaming a Task, at least until its first Pomodoro starts, in line with how the Estimate locks.

**Blocked by:** None (can start immediately)

**Status:** done

- [ ] A Task can be renamed from its ⋯ menu or by double-clicking its name, until its first Pomodoro starts.
- [ ] A name that is empty after trimming is refused.
- [ ] Past Days can't be renamed.
- [ ] Automated tests cover renaming and when it's refused.
