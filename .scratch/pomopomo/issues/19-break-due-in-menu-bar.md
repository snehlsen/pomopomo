# 19: Show a due Break in the menu bar

**What to build:** After a Pomodoro Completes, the menu bar goes back to the plain timer icon, so the user has to open the popover to see what's next. Show a distinct icon while a Break is due, and optionally a subtle idle state when nothing is timing.

**Blocked by:** None (can start immediately)

**Status:** done

- [ ] While a Break is due, the menu bar shows an icon clearly different from both the idle icon and the Running Break icon.
- [ ] The icon goes back to normal when the Break starts, is skipped, or the Day ends.
- [ ] Running, Paused and Break states in the menu bar still look different from each other.
