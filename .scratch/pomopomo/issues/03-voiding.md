# 03: Voiding

**What to build:** You can void a Running or Paused Pomodoro on purpose. It stays visible in the Day's history as Voided but counts toward nothing. Starting a new Pomodoro while one is Paused voids the Paused one automatically, so a Day never has more than one Pomodoro that is Running or Paused.

**Blocked by:** 02 (pause and resume)

**Status:** done

- [ ] A Running Pomodoro can be Voided.
- [ ] A Paused Pomodoro can be Voided.
- [ ] Voided Pomodoros appear in the Day's history as Voided and don't count toward their Task.
- [ ] Starting a new Pomodoro while one is Paused voids the Paused one.
- [ ] A new Pomodoro can't start while another is Running.
- [ ] Automated tests cover both ways a Pomodoro gets Voided and the rule of at most one unfinished Pomodoro.
