# 07: Skipped-Break Mark

**What to build:** If you start a Pomodoro while a Break is due without taking it, or end a Break before its time is up, that Pomodoro carries a Skipped-Break Mark. The mark looks clearly different from the Pause Mark and the Overrun Mark. A skipped Long Break isn't owed later: the next Set simply begins.

**Blocked by:** 06 (breaks and sets)

**Status:** done

- [ ] Starting a Pomodoro while a Break is due, without starting that Break, gives it a Skipped-Break Mark.
- [ ] Ending a Break early and then starting a Pomodoro gives it a Skipped-Break Mark.
- [ ] Taking the full Break gives no Mark.
- [ ] After a skipped Long Break, the next Break due is a Short Break, because the next Set has begun.
